# Dashboard

The home page. Admins see an organization overview; a board member sees their own donors.

- **Totals:** raised this year to date (with lifetime giving under it), donors, overdue next steps, and donors lapsed this year (gave last year, not this year). The last two link to [Follow-ups](follow-ups.md). Admins see a note when gifts have no date, since those count toward lifetime giving but not Raised YTD or [Retention](retention.md).
- **Board member load** (admins): how many donors each board member has, so new ones can be spread fairly. It shows 10 board members a page.
- **This week** (board members): what's due soon.
- **Upcoming CIC events** from the [calendar](events-calendar.md).
- **Recent activity:** the latest gifts and contacts.
