# Dashboard

The home page. Admins see an organization overview; a board member sees their own donors.

- **Totals:** raised this year to date, donors, overdue next steps, and donors lapsed this year (gave last year, not this year). The last two link to [Follow-ups](follow-ups.md).
- **Board member load** (admins): how many donors each board member has, so new ones can be spread fairly.
- **This week** (board members): what's due soon.
- **Upcoming CIC events** from the [calendar](events-calendar.md).
- **Recent activity:** the latest gifts and contacts.
