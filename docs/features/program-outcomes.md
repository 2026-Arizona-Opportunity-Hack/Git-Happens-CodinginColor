# Program outcomes (admin)

Students served and a short outcomes summary for each program: K12, AI Academy, Summer Camp, Day of Compute and General.

[Funder packets](donor-detail.md) quote them, and quarterly-update drafts in [Follow-ups](follow-ups.md) list the outcomes of the programs that donor funded.

They start with only what CIC's brief says about each program. Sample data shows made-up numbers.
